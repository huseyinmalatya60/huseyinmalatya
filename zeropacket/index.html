☎️ CUCM Architecture & Configuration Engine
Cisco Unified Communications Manager mimarisi, çağrı yönlendirme mantığı ve kurulum kılavuzları.
Publisher (Pub) & Subscriber (Sub) Rolleri

Publisher: Cluster içindeki tek yazılabilir (Read/Write) Informix veritabanına sahiptir. Lisanslama, AXL web servisleri, kullanıcı tanımlamaları ve ana konfigürasyon değişiklikleri Publisher üzerinde yapılır.

Subscriber: Veritabanını Publisher'dan salt okunur (Read-Only) olarak kopyalar (DB Replication). Cihaz sinyalleşmesi (SIP/SCCP çağrı işleme) ve CTI işlemleri Subscriber'lar tarafından yürütülür. Publisher çökse bile çağrı akışı kesintisiz devam eder.

DB Replication Durum Kodları (dbreplication runstatus)
State 0:Initializing (Başlatılıyor)
State 1:Creating Replication Pairs
State 2:GOOD / Out of Sync Check Completed (Sağlıklı)
State 3:Bad Replication / Repair Needed (Hata)
CUCM Numaralandırma ve Yönlendirme Hiyerarşisi
1. Calling Search Space (CSS): Arayan cihazın yetki alanıdır. Birkaç Partition'ın birleşiminden oluşur. ("Hangi odalara girilebilir?")
2. Partition: Mantıksal gruplama alanıdır. Pattern'ler (DN, Route Pattern) partition'lar içine konur. ("Odalardaki kilitler")
3. Route Pattern: Aranan numarayı yakalayan mantıksal şablondur (örn: 9.0[1-9]XXXXXXXXX). Numarayı bir Route List'e yönlendirir.
4. Route List & Route Group: Numarayı fiziksel Trunk/Gateway sıralamasına sokan gruptur. Biri çökerse yedek gateway'e yönlendirir.
Örnek Cisco CUBE (ISR Gateway) SIP Trunk Konfigürasyonu
voice service voip
 ip address trusted list
  ipv4 10.10.10.11 ! CUCM Pub IP
  ipv4 10.10.10.12 ! CUCM Sub IP
 allow-connections sip to sip
 sip
  registrar server

! CUCM'e Giden Dial-Peer (Outbound to CUCM)
dial-peer voice 100 voip
 destination-pattern 2...$

 session target ipv4:10.10.10.12 ! CUCM Sub IP
 dtmf-relay rtp-nte
 codec g711ulaw
 no vad

IP Telefon Kayıt (Booting) Adımları
  1. PoE & Switch Negotiation: Telefon switch'ten CDP/LLDP üzerinden güç alır ve Voice VLAN bilgisini öğrenir.
  2. DHCP Request: Telefon DHCP sunucusundan IP, Subnet, Gateway ve Option 150 (TFTP IP) bilgisini ister.
  3. TFTP File Download: Telefon Option 150 ile aldığı TFTP sunucusuna bağlanarak kendi MAC adresine özel konfigürasyon dosyasını çeker (örn: SEP001122334455.cnf.xml).
  4. SIP Register: XML dosyasının içindeki CUCM IP adresi ve port (TCP 5060) üzerinden CUCM'e SIP REGISTER mesajı atar.
  5. Active State: CUCM kaydı onaylar (200 OK) ve telefon ekranda çizgisini/numarasını göstererek kullanıma hazır hale gelir.
