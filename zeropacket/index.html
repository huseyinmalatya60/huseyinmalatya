☎️ CUCM Master Suite & Architecture Hub
CUCM Mimari Yapısı, Firewall Port Matrisi, Linux CLI Komutları ve VoIP QoS/DSCP Araçlarının Birleşimi.
🔑 Publisher (Pub) Node
• Database Master (IBM Informix Dynamic Server): Tüm küme için tek Read/Write veritabanı sahibidir.
• Configuration Hub: CUCM Administration Web panelinden yapılan tüm değişiklikler doğrudan Pub DB'ye yazılır.
• Failover Senaryosu: Pub kapansa dahi mevcut telefon çağrıları düşmez; ancak yeni konfigürasyon değişikliği yapılamaz.
📡 Subscriber (Sub) Nodes
• Read-Only DB Replica: Veritabanının salt okunur yerel bir kopyasını tutar.
• Call Processing (Cisco CallManager): IP Telefonların SIP/SCCP kayıtlarını ve aktif ses çağrı sinyalleşmesini üstlenir.
• dbreplication: Değişiklikler Pub'dan Sub'lara Informix CDR/Replication Engine (TCP 1500) ile anlık aktarılır.
Replikasyon Durum Kodları (`dbreplication runstatus`):
• State 2 (Good): Tüm düğümler tam senkronize ve DB replikasyonu sorunsuz çalışıyor.
• State 3 (Setup): Replikasyon tabloları oluşturuluyor/senkronize ediliyor.
• State 4 (Bad): Replikasyon koptu, tablolar senkron dışı (`utils dbreplication repair all` çalıştırılmalı).
CUCM Call Routing Karar Sırası (Call Pipeline):

1. Calling Search Space (CSS): Arayan cihazın/hattın yetki havuzudur. İçinde sırayla taranacak Partition listesini barındırır.
2. Partition (Bölüm): Numaraların (DN, Route Pattern) mantıksal gruplandırıldığı arayabilirlik kapsamıdır.
3. Digit Analysis (DA): Tuşlanan numara ile en spesifik eşleşen Route Pattern bulunur (Örn: 9.05XXXXXXXXXX).
4. Route List & Route Group: Aramanın hangi fiziksel gateway veya SIP Trunk'a yönlendirileceğini belirler.

Cisco IP Telefon Boot & CUCM Kayıt (Registration) Adımları:

Adım 1: Katman-1 & Katman-2 Bağlantı: PoE Switch portuna bağlanan telefon CDP/LLDP-MED protokolü ile 802.3af PoE gücü ve Voice VLAN (802.1Q) bilgisini öğrenir.
Adım 2: DHCP IP & Option 150: Telefon Voice VLAN'dan IP adresi, Subnet, Default Gateway ve **DHCP Option 150 (TFTP Server IP)** alır.
Adım 3: TFTP Dosya İndirme: Telefon, Option 150 IP'sindeki TFTP sunucusuna bağlanarak `SEP{MAC_ADRESİ}.cnf.xml` konfigürasyon dosyasını (SIP/SCCP sunucu IP'leri, Hat numaraları vb.) indirir.
Adım 4: SIP REGISTER Mesajı: Telefon konfigürasyondaki CUCM Subscriber IP'sine Port 5060/5061 (TLS) üzerinden `SIP REGISTER` isteği atarak kaydolur.

Katman-3 (DSCP) ➔ Katman-2 (CoS / 802.1p) Eşleşmesi:
• Voice Media (RTP): DSCP 46 (EF) ➔ CoS 5
• Call Signaling (SIP): DSCP 24 (CS3) ➔ CoS 3
• Video Conference: DSCP 34 (AF41) ➔ CoS 4
• Default Data: DSCP 0 (CS0) ➔ CoS 0
